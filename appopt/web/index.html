pipeline_prime_rearrange 写入值 <模式 放大系数 窗口数>，默认 1 51 10；改后即时生效
OPLUS skip 锁 (-S)
进程级，仅对配置了 :p 的包生效；关闭即清锁
OPLUS RT 避核 (pipeline)
把 RT 任务(音频/中断)赶离这些核，减少对 :p 流水线的抢占抖动；仅 pipeline 生效时起作用
OPLUS 白名单线程 (pipeline)
这些线程即使非 :p 也允许上 prime 核（内核已内置 Loading.Preload/GC Marker/mali-compiler/RBX Worker）
OPLUS pipeline 微调 (pipeline_args)
prime 核对 RT/非 pipeline 线程的容忍度；调低「非 pipeline util」+ 勾「排斥」→ 把杂线程赶出超大核(治 packing)。仅 pipeline 生效时起作用
WALT boost util 阈值
sched_min_task_util_for_boost：调低=更多任务够格 boost（默认 51，退出还原）
WALT uclamp util 阈值
sched_min_task_util_for_uclamp：调低=更多任务够格 uclamp（默认 51，退出还原）

简介

AppOpt 是一款 Android 应用 CPU 亲和性管理工具。基于规则配置文件，将指定应用的进程与线程绑定到合适的 CPU 核心（小核省电、大核高性能），配置保存后即时热加载，无需重启应用。

使用说明
  1. 规则页点击「添加」，输入应用包名，可同时配置包级默认（可选）与多条线程规则后一次保存
  2. 设置页可切换 eBPF / Proc 工作模式、cpuset 目录名、检查间隔与配置文件路径
  3. 配置文件也可直接手工编辑，保存后自动热加载
  4. 更多规则编写说明参考官网文档
